# explainer-kit

Кит для объяснялок, которые читают или показывают со сцены. Один и тот же контент собирается в два формата:

- **page** — лонгрид: оглавление слева, узкая колонка текста, широкие интерактивные «плашки», формулы, источники в конце;
- **deck** — слайды: сцена 1600×900, появление по клику, заметки докладчика, главы в прогресс-баре.

Оформление задаёт **тема**: токены цвета, шрифты, фон. Встроены три темы, любую можно поправить через config.json или сделать свою. В любом формате есть **кнопка рисования**: перо, маркер, лазер и ластик поверх контента.

Кит лежит в `kit/` рядом с этим файлом. Подробности — в `reference/`. Открывай нужный файл тогда, когда дошёл до этого шага.

## Когда брать, а когда нет

Бери, если человек хочет страницу или доклад, который объясняет что-то по шагам и где цифры можно потрогать: разбор технологии, лекцию, тизер к докладу, разбор статьи, учебный материал.

Не бери для:
- обычного документа без интерактива — это Docs;
- презентации, которую явно просят в PowerPoint, — это pptx;
- дашборда с живыми данными — это Dashboard.

## Порядок работы

### 0. Подготовка кита (один раз за сессию)

Папка скилла бывает только для чтения, поэтому кит копируется в рабочую папку:

```bash
cp -r <папка-скилла>/kit ./.kit && (cd .kit && npm install --no-audit --no-fund)
```

`npm install` ставит MathJax (формулы рендерятся при сборке) и шрифты @fontsource (они нужны для офлайн-экспорта и для скриншотов без сети). Для проверки скриншотами нужен playwright: если `require('playwright')` не работает, поставь `npm i -D playwright && npx playwright install chromium`.

### 1. Формат и тема

Это решается до того, как что-то писать.

- **Формат.** Будут выступать со сцены или на созвоне — `deck`. Будут читать сами, возвращаться к странице, делиться ссылкой — `page`. Если из запроса непонятно, спроси одним вопросом.
- **Тема.** По умолчанию `abyss`: тёмная вода, акулы, Cormorant + Golos Text + JetBrains Mono. Для светлого делового текста бери `paper`, для инженерных разборов — `blueprint`. Если человек описал свой стиль (цвета бренда, шрифты), возьми ближайшую тему и переопредели токены в config.json, см. `reference/themes.md`.
- **Объём.** Лонгрид: тезис плюс 5–12 разделов. Доклад: примерно 1–1,5 слайда на минуту, одна мысль на слайд.

### 2. Материал раньше вёрстки

Сначала собери факты, потом верстай.

- Всё, что описывает мир сейчас (цены, версии, рейтинги, кто что выпустил), проверь поиском на сегодняшнюю дату.
- Числа бери из первоисточника: статьи, конфигов, документации.
- Если число посчитано тобой, пометь его как оценку и покажи формулу расчёта в примечании под виджетом. Сверь оценку с опубликованными цифрами, если они есть.
- Ссылки на источники собирай сразу, в конце они пойдут списком.

### 3. Проект из шаблона

```bash
node .kit/new.mjs <папка> --format page|deck --theme abyss|paper|blueprint --title "Название"
```

В папке появятся:
- `config.json` — заголовок, формат, тема, токены;
- `content.html` — разметка;
- `widgets.js` — интерактив;
- `style.css` — стили только этой страницы;
- `assets/` — картинки.

Шаблон уже рабочий: в нём есть пример каждого компонента. Замени текст и виджеты на свои, а структуру и классы оставь.

- Разметка лонгрида: `reference/page.md`.
- Разметка слайдов: `reference/deck.md`.
- Виджеты и хелперы: `reference/widgets.md`.
- Формулы: `reference/math.md`. Пиши `<m>…</m>` в строке и `<M>…</M>` отдельной формулой, TeX без кириллицы.

### 4. Сборка

```bash
node .kit/build.mjs <папка>                     # dist/index.html, полный HTML-документ
node .kit/build.mjs <папка> --target artifact   # фрагмент для Artifact-инструмента claude.ai
node .kit/build.mjs <папка> --offline           # один самодостаточный файл: шрифты и картинки внутри
```

При `--target artifact` сборщик печатает `file_path`, карту `files` (картинки и спрайт темы) и `icon`. Передай их в Artifact publish как есть.

### 5. Проверка

```bash
node .kit/check.mjs <папка>/dist/index.html [--ink]
```

Скрипт делает скриншоты:
- для страницы — каждого раздела на 1440 и 400 px;
- для слайдов — каждого слайда на последнем шаге.

Ещё он печатает ошибки консоли, элементы, которые вылезают за край, и мелкий текст на слайдах. С флагом `--ink` дополнительно проверяется рисование.

Открой скриншоты через Read и посмотри глазами: подписи не наезжают, графики читаются, ничего не обрезано. Исправь и проверь ещё раз один раз, без бесконечного цикла. Что именно смотреть — `reference/checks.md`.

### 6. Сдача

- В claude.ai опубликуй артефакт, сборка с `--target artifact`. В ответе дай одну фразу о том, что это за страница.
- В Claude Code или по просьбе «дай файл» отдай `dist/index.html`. Если нужен один файл без интернета, собери с `--offline`.
- Если прислали правку, поправь исходники в папке проекта и пересобери. Собранный HTML руками не правят.

## Правила, без которых получается не то

Это выжимка, подробно — в `reference/design.md`.

1. **Тезис первым.** Hero — это заголовок-тезис, подзаголовок курсивом и живая схема, которая видна сразу и объясняет главное ещё до чтения.
2. **На слайде только тезисы.** Короткие фразы, цифры, схема. Объяснения уходят в `<aside class="notes">`. Абзац на слайде — ошибка.
3. **Один виджет — одна мысль.** У плашки есть заголовок, подпись-ярлык справа, сама схема и примечание с допущениями. Виджет полностью нарисован в покое, анимация идёт только пока он виден, `prefers-reduced-motion` соблюдается.
4. **Числа честные.** Реальные значения с источником, оценки подписаны как оценки. На графиках деления стоят на реальных значениях. Если величины отличаются на порядки, шкала логарифмическая.
5. **Просто для неспециалиста.** Термин объясняется при первом появлении. Математика — когда она что-то объясняет, и рядом всегда словесная расшифровка.
6. **Цвет — только токенами.** В CSS это `var(--accent)` и другие токены, в SVG — `COL.accent` и `mix(COL.accent, 20)`. Литеральные цвета ломают смену темы.
7. **Русская типографика.** «Ёлочки», настоящий минус «−», запятая в дробях, пробелы в тысячах. Всё это даёт `fmt()`.
8. **Картинки.** Фото не обрезаются (`.photo`). Мемы и скриншоты кладутся в `.exhibit` и открываются в лайтбоксе по клику. Картинка должна работать на мысль, не на кринж.
9. **Источники в конце** и дата актуальности в eyebrow героя.

## Рисование

Кнопка с пером: на странице она справа внизу, на слайдах — в нижней панели. То же делает клавиша **D**.

- Инструменты: перо **P**, маркер **M**, лазер **L** (исчезает сам), ластик **E**.
- Цвета **1–4** берутся из темы, плюс три толщины.
- Отмена — **Ctrl+Z**, очистка — **C**, скрыть рисунки — **H**, выход — **Esc**.

На слайдах у каждого слайда свой рисунок. На странице штрихи приколоты к документу и прокручиваются вместе с ним. Выключить рисование: `"draw": false` в config.json. Подробности — `reference/drawing.md`.

## Темы коротко

| тема | вид | шрифты |
|---|---|---|
| `abyss` | тёмная вода, лучи света, морской снег, акулы; вода темнеет по мере чтения | Cormorant / Golos Text / JetBrains Mono |
| `paper` | светлая серо-зелёная бумага, чернильно-синий акцент; есть ночной вариант | Literata / Onest / IBM Plex Mono |
| `blueprint` | синий лист с измерительной сеткой, сигнально-жёлтый акцент | Unbounded / Commissioner / JetBrains Mono |

Переопределить токены или шрифты: `"tokens": {"--accent": "#…"}`, `"fonts": {"google": "…", "display": "\"Font\", serif"}`. Новая тема — это папка с `theme.css` и `theme.json`, `"theme": "./my-theme"`. Контракт токенов — `reference/themes.md`.

- [ ] Hero с тезисом и живой схемой. На слайдах только тезисы, остальное в заметках.
- [ ] `check.mjs` без ошибок и вылезаний. Скриншоты просмотрены на десктопе и телефоне (страница) или все слайды (доклад).
- [ ] Оценки подписаны как оценки, формула расчёта в примечании.
