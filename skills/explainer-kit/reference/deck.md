# Формат deck: слайды

`content.html` — это последовательность `<section class="slide">`. Сцену 1600×900, нижнюю панель, заметки, справку и рисование добавляет кит.

## Слайд

```html
<section class="slide" id="s-price" data-ch="1">
  <div class="eyebrow"><b>01</b><span class="dash"></span>API</div>
  <h2>Цена токена — <em>только начало</em></h2>
  <p class="thesis" data-f="1">Первый тезис по клику.</p>
  <p class="thesis" data-f="2">Второй тезис.</p>
  <aside class="notes">Что сказать голосом.</aside>
</section>
```

| атрибут | что делает |
|---|---|
| `data-ch="1"` | глава слайда. Подписи глав задаются в config.json: `"chapters": {"0": "Старт", "1": "API"}`. Пустая строка — глава без подписи. |
| `data-f="n"` | элемент появится на n-м клике |
| `data-steps="3"` | число шагов, если шаги рисует виджет, а не `data-f` |
| `id` | нужен для ссылок `data-go="s-price"` (клик переходит на слайд) и для `#номер` в адресе |
| `<aside class="notes">` | заметки докладчика (клавиша N), на слайде не видны |

Все размеры — в пикселях сцены (1600×900). Шкала текста задана в `deck.css`: h1 112, h2 60, тезис 36, lead 25, текст 20, ярлыки 14.

## Типы слайдов

| класс | для чего |
|---|---|
| `s-title` | титул и «Вопросы?»: контент по центру по вертикали; `h1 > .sub` — подзаголовок |
| `s-center` | всё по центру: цитата, одна мысль |
| `s-split` | eyebrow и h2 сверху, ниже две колонки: текст и плашка |
| `s-big` | одна огромная цифра `.big` и подпись `.lead` |
| `s-quote` | `<blockquote>` и `<cite>` |
| без класса | свободная раскладка: `.row`, `.col`, `.grow`, `.fill`, `.push` (прижать вниз), `.panel` |

Компоненты лонгрида работают и здесь: `.plate`, `.cards/.card`, `.grid2/.grid3`, `table.t`, `.eq`, `.exhibit`, `ul.ticks`.

## Клавиши (их показывает справка «?»)

→ или пробел — дальше; ← — назад; N — заметки; F — полный экран; A — спрятать фон; D — рисовать; Home и End — в начало и в конец. Свайп на телефоне листает слайды.

## Виджеты на слайде

- `onShow(el, enter, leave)` — слайд открылся или закрылся: запустить или остановить анимацию.
- `onStep(el, step => …)` — перерисовать схему на каждом клике. На странице тот же виджет получает `Infinity`, то есть финальное состояние.
- `loop(el, dt => …)` — анимация идёт, только пока слайд активен.
- Слайдер и кнопки работают во время доклада. Стрелки не листают слайды, пока фокус на слайдере.

## Темп и объём

- 10–15 минут — это 12–20 слайдов. Лекция на 90 минут — 50–70.
- Первые слайды: титул → кто я (фото без обрезки) → план (карточки с `data-go`).
- Каждые 5–7 слайдов — разрядка: большая цифра, мем-экспонат или живой виджет.
- Финал: выводы → «Вопросы?» → источники.
