# Темы

Тема — это папка с двумя файлами:

- `theme.css` — токены на `:root`, при желании ещё светлый и тёмный варианты;
- `theme.json` — шрифты, фон (ambient) и иконка артефакта.

Встроенные темы лежат в `kit/themes/`, своя тема подключается путём: `"theme": "./my-theme"`.

## Контракт токенов

Каждая тема определяет все токены. Компоненты кита используют только их.

| токен | назначение |
|---|---|
| `--bg` | фон страницы (сплошной) |
| `--surface`, `--surface-2` | фон плашек и карточек; второй — плотнее (рамки картинок) |
| `--ink`, `--ink-2`, `--muted` | текст: основной, второстепенный, подписи |
| `--line`, `--line-2` | линии: тонкие и заметные |
| `--accent`, `--accent-ink` | главный акцент и цвет текста на нём |
| `--accent-2`, `--warn`, `--extra` | второй акцент (интерактив), предупреждение или контраст, четвёртая серия |
| `--f-display`, `--f-body`, `--f-mono` | гарнитуры с запасными шрифтами |
| `--display-weight`, `--display-tracking` | начертание и трекинг заголовков |
| `--em-style` | `italic` или `normal`: как выглядит акцент в заголовке |
| `--display-scale` | множитель размеров h1–h3 (0,7–1) для широких или тяжёлых гарнитур |
| `--radius`, `--blur`, `--shadow` | скругления, размытие под плашками, тень рамок |
| `--icon-stroke`, `--icon-cap` | толщина и окончания линий иконок |
| `--ray`, `--vignette`, `--grid-major`, `--grid-minor`, `--grid-cell` | параметры фона, если он их использует |

Производные (`--accent-soft`, `--accent-2-soft`, `--warn-soft`, `--extra-soft`, `--scrim`) кит считает сам через `color-mix`.

## Светлая и тёмная

- `"scheme": "dark"` или `"light"` — один задуманный вид. В `:root` ставится `color-scheme`, фон задаётся явно.
- `"scheme": "auto"` — светлые значения на `:root`, тёмные повторяются дважды: в `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) {…} }` и в `:root[data-theme="dark"] {…}`. Так тема слушается и системы, и переключателя в просмотрщике claude.ai. Пример — `themes/paper/theme.css`.

## theme.json

```json
{
  "name": "abyss",
  "scheme": "dark",
  "icon": "wave",
  "fonts": {
    "google": "https://fonts.googleapis.com/css2?family=…&display=swap",
    "fontsource": [{ "family": "Cormorant", "pkg": "cormorant", "weights": [400, 500, 600], "italic": true }]
  },
  "ambient": { "type": "ocean", "…": "…" }
}
```

- `fonts.google` — ссылка для обычной сборки и для артефакта. Это единственный хост шрифтов, который пускает CSP артефактов.
- `fonts.fontsource` — те же шрифты из npm-пакетов `@fontsource/<pkg>`. Они нужны для `--offline` и для скриншотов без сети. Подмножества по умолчанию: cyrillic и latin; другие задаются через `"fontSubsets"` в config.json.
- Шрифты выбирай **с кириллицей**. Перед использованием проверь, что у семейства на Google Fonts есть подмножество cyrillic.

## Фон (ambient)

| type | что рисует | параметры |
|---|---|---|
| `ocean` | градиент воды, который темнеет с прокруткой (`stops`), лучи света (`rays`), морской снег (`snow`, светящиеся точки `glow`), существа из спрайта (`sprite` 4×4 кадра, `creatures`) | `deckDepth` — глубина на слайдах; `swimDeck: false` — на слайдах существа стоят на месте; `swim: false` — и на странице |
| `grid` | измерительная сетка из `--grid-*` | — |
| `plain` | только `--bg` | — |
| `none` | ничего | — |

Любой тип принимает `"grain": 0.06` (шум) и `"vignette": true`. Клавиша **A** на слайдах прячет декоративные слои.

В config.json фон можно поменять, не трогая тему: `"ambient": "plain"` или `"ambient": {"type": "ocean", "creatures": 0}`.

## Подстройка без новой темы

```json
{
  "theme": "paper",
  "tokens": { "--accent": "#7a1fa2", "--radius": "0px" },
  "tokensDark": { "--accent": "#d59cf0" },
  "fonts": { "google": "https://fonts.googleapis.com/css2?family=PT+Serif:ital,wght@0,400;0,700;1,400&display=swap", "display": "\"PT Serif\", Georgia, serif" }
}
```

## Новая тема за пять шагов

1. Скопируй ближайшую тему: `cp -r kit/themes/paper my-theme`.
2. В `theme.css` замени значения всех токенов. Первой строкой оставь комментарий с замыслом: «что это за мир и почему такие цвета».
3. В `theme.json` — имя, шрифты (google и fontsource), фон, иконку.
4. В config.json проекта: `"theme": "./my-theme"`.
5. Собери шаблон в новой теме и проверь контраст: текст `--ink-2` на `--surface` должен читаться; акцент должен работать и на фоне, и на плашке.

Избегай шаблонных «AI-видов»: кремовый фон с терракотой, чёрный с кислотно-зелёным, фиолетово-синий градиент, Inter или Space Grotesk «по умолчанию». У темы должна быть идея из мира темы: вода, бумага, чертёж.
