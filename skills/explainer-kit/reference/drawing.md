# Рисование поверх страницы

`kit/core/draw.js` и `draw.css` подключаются всегда, если в config.json нет `"draw": false`.

## Как включить

- **Страница:** круглая кнопка с пером справа внизу.
- **Слайды:** кнопка с пером в нижней панели, рядом со стрелками.
- **Клавиатура:** D (в русской раскладке В) включает и выключает режим.

Когда режим включён, сверху по центру появляется панель инструментов.

## Инструменты и клавиши

| | клавиша | что делает |
|---|---|---|
| перо | P | обычная линия; со стилусом толщина зависит от нажима |
| маркер | M | широкая полупрозрачная полоса, чтобы подчеркнуть или выделить |
| лазер | L | светящийся след, гаснет через 1,4 с; ничего не остаётся |
| ластик | E | стирает штрихи целиком |
| цвет | 1–4 | `--accent`, `--accent-2`, `--warn`, `--ink` темы |
| толщина | кнопки | три размера |
| отменить | Ctrl/⌘+Z | отменяет и рисование, и стирание, и очистку |
| очистить | C | стирает всё на этом слайде или на странице; отменяется |
| скрыть | H | прячет рисунки, не удаляя их |
| выйти | Esc | выключает режим, рисунки остаются видны |

## Поведение

- **Слайды.**
  - У каждого слайда свой слой: вернулись на слайд — рисунок на месте.
  - Координаты в пикселях сцены, поэтому рисунок не съезжает при изменении размера окна.
  - Стрелки и пробел листают слайды и в режиме рисования. Свайп в режиме рисования отключён.
- **Страница.**
  - Штрихи приколоты к документу и прокручиваются вместе с текстом.
  - Холст размером с окно перерисовывается при прокрутке, поэтому длинная страница не создаёт гигантский canvas.
  - Колесо мыши прокручивает страницу и в режиме рисования. Касание пальцем в режиме рисования рисует, поэтому для прокрутки на телефоне режим выключают.
- **Сохранение.** По умолчанию рисунки живут до перезагрузки. С `"draw": {"persist": true}` они сохраняются в localStorage этого браузера. Если хранилище недоступно, это не ломает страницу.
- **Цвета.** `"draw": {"colors": ["--accent", "--warn", "--ink"]}` — свой набор токенов, до 9 штук.

## API для виджетов

`Ink.toggle(true|false)`, `Ink.clear()`, `Ink.undo()`, `Ink.on` (включён ли режим). Слайды при смене шлют `deck:change` на `document`, по этому событию рисунок перерисовывается.
