# Виджеты: хелперы и проверенные приёмы

`widgets.js` выполняется после ядра кита. Все хелперы — глобальные функции из `kit/core/runtime.js`. Каждый виджет оборачивают в IIFE, которая сразу выходит, если её элемента нет на странице:

```js
(() => {
  const svg = $('#calc'); if (!svg) return;
  // …
  draw();            // первый кадр рисуем сразу: страница полная без взаимодействия
})();
```

## Хелперы

| хелпер | что делает |
|---|---|
| `$(sel, root)`, `$$(sel, root)` | querySelector; `$$` возвращает массив |
| `S(tag, attrs, parent)` | создать SVG-элемент. `fill: COL.accent` и другие var() уходят в `style`, поэтому цвета следуют теме |
| `T(parent, x, y, text, attrs)` | SVG-текст: моноширинный, по умолчанию 13 px и цвет `--muted` |
| `H(tag, attrs, html, parent)` | HTML-элемент |
| `COL` | цвета темы: `accent, accent2, warn, extra, ink, ink2, muted, line, line2, surface, surface2, bg`, плюс старые имена `lamp, bio, coral, violet, bone, fog` |
| `SERIES` | цвета серий по порядку: accent, accent2, warn, extra, ink |
| `mix(c, pct)` | полупрозрачный цвет: `mix(COL.accent, 25)` |
| `cssColor(c)` | настоящий цвет для `<canvas>`, который CSS-переменные не понимает |
| `chips(box, btn => …)` | ряд кнопок-переключателей; нажатая получает `.on` |
| `slider('#id', v => подпись, v => перерисовать)` | range с `<output>`; возвращает геттер значения. Колбэк срабатывает только на ввод, первый кадр рисуй сам |
| `chart(svg, {x, y, box})` | оси и сетка на линейной или логарифмической шкале; возвращает `{X, Y, line, dot, vline, g}` |
| `loop(el, (dt, now) => …)` | анимация, которая идёт только пока `el` виден (на слайде — пока слайд открыт); при reduced motion рисует один кадр |
| `onShow(el, enter, leave)` | слайд открылся или элемент виден на странице |
| `onStep(el, step => …)` | клик на слайде; на странице `Infinity`, то есть финальный кадр |
| `whenVisible(el, start, stop)` | IntersectionObserver обёрткой |
| `fmt(v, d)` | число в языке страницы: «1 048 576», «−0,5» |
| `fmtBytes(b)`, `fmtTok(n)`, `sci(v)` | «3,4 ГБ», «256K», «1,2·10⁻³» |
| `rng(seed)` | детерминированный генератор: одинаковая картинка при каждой загрузке |
| `clamp`, `lerp`, `REDUCED` | мелочи |
| `icon(name)` | SVG-иконка: pen, marker, laser, eraser, undo, trash, eye, x, left, right, expand, notes |

## `chart()`

```js
const c = chart(svg, {
  box: [90, 20, 970, 350],                       // поля: левое, верхнее, правое, нижнее (в координатах viewBox)
  x: { min: 1024, max: 1048576, log: true, ticks: [1024, 16384, 262144, 1048576], fmt: fmtTok, title: 'токенов' },
  y: { min: 1e6, max: 3e11, log: true, ticks: [1e6, 1e8, 1e10], fmt: fmtBytes }
});
c.line(points, { stroke: COL.accent });          // points = [[x, y], …]
c.vline(L); c.dot(L, value, { fill: COL.accent });
T(c.g, c.X(L) + 8, c.Y(value) - 8, fmtBytes(value), { fill: COL.accent });
```

Деления ставь на значения, которые реально есть на графике. Если величины отличаются на порядки, бери логарифмическую шкалу и пиши это в ярлыке плашки.

## Приёмы

Каждый приём уже работал на реальных страницах.

**1. Живая схема в hero.** Процесс разворачивается сам: поток токенов, рост кривой. Над схемой счётчик («токенов: 392»), под ней примечание с реальным масштабом. Начальное состояние — середина процесса, а не пустота: `let n = 300; draw(n);`. Анимация идёт через `loop()` или `setInterval` внутри `whenVisible`.

**2. Калькулятор.** Слайдер (контекст, срок, размер) плюс переключатели (модель, режим). Рисуются лог-лог линии серий, вертикальная пунктирная линия на выбранном значении, точки на пересечениях. Легенда с текущими значениями: цвет серии, имя, число справа. В примечании формула оценки и сверка с опубликованными цифрами.

**3. Сборка по шагам.** Механизм показан как последовательность: вход → веса → результат. Переключатели выбирают пример (`i = 1, 2, 3`) и режим сравнения («как в статье» против «наивно»). Для весов подходит тепловая карта: прямоугольники с `fill-opacity` по значению и числом в процентах внутри.

**4. Игрушечный эксперимент.** Настоящая маленькая симуляция прямо в браузере: случайные векторы, `rng()` для повторяемости, кэш результатов. Слева кривая метрики против параметра, справа разрез по группам при текущем значении. В примечании честно написано, что это игрушка и что именно она показывает.

**5. Стопка или лента.** Ряд ячеек (слои модели, этапы, дни). Цвет ячейки — тип, наведение или клик выводит описание в примечание. Хорошо подходит для конфигов: показывает реальный список из config.json.

**6. Выбор top-k или порога.** Полоски-оценки, слайдер k. Выбранные полоски закрашены `COL.accent`, остальные `COL.muted` с прозрачностью. Под схемой: «читаем k из N, это x%».

**7. Схема по кликам на слайде.** `onStep(svg, s => draw(s === Infinity ? last : s))`. Каждый клик добавляет один элемент. На странице показывается финальный кадр.

## Правила

- В покое виджет полный: нарисован сразу, без прокрутки и кликов.
- Подписи не вылезают за `viewBox`. У правого края подпись выравнивается по концу (`'text-anchor': 'end'`) и сдвигается влево.
- Числа в подписях проходят через `fmt()` и форматтеры, не через `toFixed`.
- Цвета берутся из `COL` или `mix()`. Если нужен «просто серый», это `COL.muted`.
- Текст на SVG-схеме слайда — от 13 px. На странице — от 11,5 px в координатах viewBox 1000.
- Одна плашка — одна мысль. Если хочется третий переключатель, скорее всего, нужна вторая плашка.
